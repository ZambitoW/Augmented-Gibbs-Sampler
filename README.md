# Augmented-Gibbs-Sampler

## Files
The script folder holds our scripts to create our dataset 
The data folder holds our dataset as well as the full tuberculosis genonme

- augmentedGibssSampler.py is our algorithm described in proposal that combines Simulated annealing, entropy and multiple restart
- entropyGibbsSampler.py is our algorithm that only has entropy to isolate its effect
- gibbsSampler.py is our baseline like the rosalind assignment
- RandomRestartGibbsSampler.py is our algorithm with multiple restarts
- SAGibbsSampler.py is our algorithm with simulated annealing to isole its effect
- SAGreedySampler.py is our algorithm with simulated annealing and the greedy warm start
- utils.py has methods used in many algorithms most of them implemented for in rosalind
